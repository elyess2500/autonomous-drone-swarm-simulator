# Curated historical validation evidence

These are selected public copies of approved engineering evidence, not new simulation runs. The complete original evidence and frozen baselines remain in a private byte-identical archive. Unselected traces, fault-injection dumps, machine-local orchestration, environment-location records and redundant outputs are deliberately not distributed.

[Provenance manifest](provenance.json) records original repository-relative location, original SHA-256, public location and public SHA-256 for each copy. A changed public hash identifies a path-sanitized copy, never a byte-identical original. Source-manifest hashes inside historical records remain historical values; they are not assertions that this curated directory contains the entire old archive. Numeric measurements, dates, test counts, conclusions and scientific hashes have not been rewritten.

## Private baselines

Historical `baseline_location.txt` records pointed outside the public repository and are intentionally omitted. They are not needed by the supported engine, ordinary tests, portable golden fixture, research runner or deterministic analysis. References to old `benchmarks/results/` paths in historical prose describe the private archive; use this directory for the selected public evidence. The historical closure/orchestration scripts are not public reproduction entry points.

## Reproduce current contracts

Use [validation commands](../validation.md) and the [research artifact guide](../../research/README.md). The approved golden bundle and all locked research inputs/raw results remain unchanged. No golden, research observation or analysis result was regenerated for publication.
